# Avito Hunt

Telegram-бот для быстрого поиска новых выгодных объявлений на Avito.

## MVP

Первая версия работает только с iPhone:

1. получает новые объявления;
2. нормализует модель, память, состояние и комплект;
3. оценивает рыночную цену по сопоставимым объявлениям;
4. отбирает варианты со значимой скидкой;
5. отправляет пользователю уведомление в Telegram со ссылкой и объяснением, почему цена выглядит выгодной.

Подробные границы и логика MVP описаны в [docs/MVP.md](docs/MVP.md).

## Состояние

Проект находится на этапе проектирования MVP. Код сбора объявлений, оценки цены и Telegram-бота будет добавляться поэтапно. Сервер и автоматическое развёртывание будут настроены после получения SSH-доступа.

## Безопасность

- Секреты хранятся только в `.env` или в секретах сервера.
- `.env`, SSH-ключи, локальные базы и логи не коммитятся.
- `.env.example` содержит только названия настроек без реальных значений.
