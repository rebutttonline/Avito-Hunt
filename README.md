# Avito Hunt

Telegram-бот для быстрого поиска новых выгодных объявлений на Avito.

## MVP

Первая версия работает только с iPhone:

1. получает новые объявления;
2. нормализует модель, память, состояние и комплект;
3. оценивает рыночную цену по сопоставимым объявлениям;
4. отбирает варианты со значимой скидкой;
5. отправляет пользователю уведомление в Telegram со ссылкой и объяснением, почему цена выглядит выгодной.

Подробные границы и логика MVP описаны в [docs/MVP.md](docs/MVP.md).

## Возможности текущей версии

- единая встроенная панель Telegram: настройки, пауза/продолжение и статус;
- навигация редактирует одно сообщение и не засоряет чат новыми ответами;
- отслеживание всех поколений iPhone по умолчанию с необязательными фильтрами;
- персональные настройки модели, памяти, региона и минимальной скидки;
- онбординг, тихие часы и персональный дневной лимит уведомлений;
- нормализация модели, памяти и состояния iPhone;
- устойчивая оценка рыночной цены с отсечением выбросов;
- автоматическая медианная оценка без ручного ввода желаемой цены;
- уровни «обычная цена», «выгодно», «очень выгодно» и «подозрительно дёшево»;
- фильтрация обмена, поломок, копий, аксессуаров, запчастей и фиктивных цен;
- защита от повторных уведомлений, URL-дублей и переопубликованных объявлений;
- история изменения цены и повторное уведомление при её снижении;
- оценка риска по аккумулятору, Face ID, True Tone, ремонту, комплекту и предоплате;
- демонстрационный рынок, работающий без внешнего источника;
- Market Lab на 160 синтетических сценариях и эмулятор событий поставщика;
- иерархическая оценка по городу, соседним регионам и рынку России;
- безопасный административный импорт JSON/CSV;
- обратная связь по каждому предложению и приглашения для закрытого теста;
- встроенная админ-панель, контроль источника и ежедневная сводка;
- политика удаления аккаунта и автоматическая очистка событий старше 180 дней;
- PostgreSQL для пользователей, объявлений и истории отправок;
- безопасный JSON-feed как интерфейс подключения источника;
- изолированный запуск бота, обработчика и базы через Docker Compose;
- CI, автоматическое развёртывание, health checks и ежедневные бэкапы.

Пока не настроены `TELEGRAM_BOT_TOKEN` и `SOURCE_JSON_URL`, контейнеры работают в режиме ожидания. Это позволяет развернуть и проверить инфраструктуру до добавления секретов и источника данных.

## Быстрый запуск для разработки

Требуются Docker и Docker Compose v2.

```bash
cp .env.example .env
docker compose up -d --build
docker compose ps
docker compose logs -f bot worker
```

Проверки без Docker:

```bash
python -m pip install '.[dev]'
ruff check .
pytest -q
```

## Безопасность

- Секреты хранятся только в `.env` или в секретах сервера.
- `.env`, SSH-ключи, локальные базы и логи не коммитятся.
- `.env.example` содержит только названия настроек без реальных значений.
