# Market Lab и эмулятор поставщика

## Лаборатория оценки

Market Lab запускается из админ-панели Telegram или командой:

```bash
python -c "from avito_hunt.market_lab import format_lab_report, run_market_lab; print(format_lab_report(run_market_lab()))"
```

Тест содержит 160 полностью вымышленных сценариев: 8 моделей, 5 регионов,
четыре ценовых уровня и экстремальные выбросы. Отчёт показывает точность
классификации, ошибку рыночной медианы и долю ложных выгодных предложений.

## Иерархическая оценка

Алгоритм выбирает самый узкий рынок с достаточным числом наблюдений:

1. та же модель, память, состояние и регион;
2. те же параметры в текущем и соседних регионах;
3. те же параметры по России.

При расширении географии уверенность автоматически понижается. В уведомлении
показываются медиана, межквартильный диапазон и процент сопоставимых объявлений,
которые дороже кандидата.

## Эмулятор API

Эмулятор работает только во внутренней Docker-сети и не публикует порт сервера:

```bash
docker compose --profile tools up -d provider-emulator
```

URL для тестового воркера:

```text
http://provider-emulator:8080/items?scenario=timeline
```

Сценарий `timeline` последовательно отдаёт базовый рынок, новое выгодное
объявление, снижение его цены, снятие объявления и ошибку 503. Также доступны
`baseline`, `invalid`, `empty` и `error`.

## Импорт через Telegram

В админ-панели выберите `Импорт JSON/CSV` и отправьте файл до 1 МБ и 1000 строк.
Импорт проходит нормализацию, фильтры, дедупликацию и настоящую рыночную оценку.
Пример находится в `examples/import_sample.json`.
