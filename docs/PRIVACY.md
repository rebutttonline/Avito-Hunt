# Политика конфиденциальности Avito Hunt (MVP)

Дата редакции: 18 августа 2026 года.

Avito Hunt хранит только данные, необходимые для работы Telegram-бота:

- Telegram chat ID и имя пользователя;
- настройки моделей, памяти, региона, скидки, тихих часов и лимита;
- историю отправленных уведомлений;
- добровольные оценки предложений;
- код приглашения и связь с пригласившим тестировщиком.

Бот не запрашивает паспортные, платёжные или контактные данные продавцов, не
читает личную переписку и не участвует в оплате товара. Токен Telegram хранится
в закрытой конфигурации сервера.

Пользователь может удалить свои пользовательские данные командой `/delete_me`.
Технические обезличенные журналы могут временно сохраняться для безопасности и
диагностики.

Перед публичным коммерческим запуском документ должен пройти юридическую
проверку и получить реквизиты оператора сервиса.
