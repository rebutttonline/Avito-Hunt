# Поставщики данных для Avito Hunt

Актуальность исследования: 17 августа 2026 года.

## Вывод

В открытых материалах рассмотренных сервисов не найдено подтверждение, что они являются официально лицензированными Avito поставщиками публичной ленты чужих объявлений. До оплаты и интеграции необходимо получить письменное подтверждение прав на сбор и коммерческую передачу данных, а также права клиента использовать данные для Telegram-уведомлений и производной аналитики.

## Короткий список

### 1. Rest-App — первый кандидат на пилот

- API: `https://rest-app.net/api`
- Заявлены JSON, обновление базы каждую секунду, фильтры по категории, региону, городу, тексту, цене и времени появления.
- Тариф: 4 000 ₽ за 30 дней; тестовый период 15 дней.
- За API стоит идентифицированный ИП, опубликованы ИНН, ОГРНИП и пользовательское соглашение.
- Ограничение теста: цена может быть случайной, поэтому проверить алгоритм оценки рынка без договорённости о полноценном тесте нельзя.
- Нет публичного подтверждения лицензии или письменного разрешения Avito на перепродажу данных.

### 2. ADS-API — бюджетный технический кандидат

- API: `https://ads-api.ru/api`
- База пополняется каждую минуту; заявлены фильтры по источнику, категории, региону, городу и актуальности.
- Подходящий для MVP тариф без телефонов: 2 000 ₽ в месяц; запрос не чаще одного раза в 5 секунд.
- Тестовый период 14 дней, но тест возвращает цену `0`, поэтому для нашего price scoring он практически непригоден.
- Сам поставщик предупреждает о возможных пропусках.
- На изученных публичных страницах не найдено подтверждение лицензии Avito и прозрачных реквизитов оператора.

### 3. ApiAd — современный API, требуется усиленная проверка

- API: `https://apiad.ru/`
- Есть свежая JSON-документация, пагинация, даты публикации и обработки, цена, параметры, продавец и аналитические поля.
- Публичная цена и полноценные лимиты не указаны.
- В оферте исполнитель обозначен как физическое лицо без публичных реквизитов.
- Нет публичного подтверждения лицензии Avito.

## Не подходят как основной feed сейчас

### OpenAVI

Готовый сервис мониторинга с Telegram и веб-интерфейсом. Публичной документации интеграционного API не найдено. Сайт прямо описывает прокси, browser fingerprints и антибан, поэтому считать его лицензированным источником нельзя. Продукт также дублирует значительную часть Avito Hunt.

### Smart Price For Avito (SPFA)

API ориентирован на анализ известных ссылок/ID и получение ценовых рекомендаций, а не на поставку непрерывной ленты новых объявлений. Может пригодиться позднее для независимой проверки оценки цены.

## Вопросы поставщику до оплаты

1. Есть ли у компании договор, лицензия или письменное разрешение Avito на автоматизированный сбор и коммерческую передачу данных клиентам?
2. Разрешено ли использовать данные в коммерческом Telegram-сервисе с платными пользователями?
3. Разрешено ли хранить историю объявлений и строить производные показатели: медианную цену, скидку, confidence score?
4. Какие поля разрешено показывать пользователю? Можно ли показывать заголовок, цену, фотографию и прямую ссылку?
5. Какие ограничения действуют для персональных данных продавца? Для MVP телефоны и имена нам не нужны.
6. Какова полнота покрытия категории смартфонов по сравнению с выдачей Avito?
7. Каковы медианная и p95-задержка от публикации объявления до появления в API?
8. Есть ли стабильный ID, признак повторной публикации, время обновления и признак снятия объявления?
9. Каковы rate limits, месячная квота, SLA, порядок уведомления об изменениях API и возврат средств при длительном сбое?
10. Можно ли получить 3–7 дней полноценного теста с реальными ценами и документами от юридического лица/ИП?

## Текст первого обращения

> Разрабатываем Telegram-сервис Avito Hunt для уведомления пользователей о новых объявлениях iPhone с ценой ниже рыночной. Нам нужны только публичные поля: стабильный ID, ссылка, заголовок, цена, параметры телефона, регион, время публикации/обработки и признак актуальности. Телефоны и иные контактные данные продавцов не нужны. Подтвердите, пожалуйста, письменно: (1) наличие у вас права собирать и коммерчески передавать эти данные; (2) право использовать их в коммерческих уведомлениях и хранить историю для производной ценовой аналитики; (3) покрытие, задержку, лимиты, SLA и стоимость; (4) возможность теста с реальными ценами.

## Пилот

Для двух лучших поставщиков проводится параллельный тест 72 часа:

1. Один набор запросов по iPhone в Москве.
2. Опрос каждые 30–60 секунд в пределах лимитов.
3. Измерение задержки, дублей, пропусков, доли пустых параметров и ошибок API.
4. Ручная сверка случайной выборки с Avito.
5. Проверка стабильности ID и корректности цены, модели, памяти, региона и времени.
6. Выбор поставщика только после технического теста и проверки письменных условий.
