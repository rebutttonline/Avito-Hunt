# Подключение источника объявлений

Avito Hunt намеренно не содержит скрытого скрейпера. Источник должен быть разрешённым, устойчивым и отдавать JSON по HTTPS. URL задаётся переменной `SOURCE_JSON_URL`.

Поддерживается массив объявлений или объект с массивом `items`:

```json
{
  "items": [
    {
      "id": "external-123",
      "title": "iPhone 15 Pro 256 ГБ",
      "price": 75000,
      "url": "https://example.test/items/123",
      "storage_gb": 256,
      "condition": "used",
      "region": "Москва",
      "published_at": "2026-08-17T10:00:00Z"
    }
  ]
}
```

Обязательные поля:

- `id` или `external_id` — постоянный уникальный идентификатор;
- `title` — заголовок с моделью iPhone;
- `price` — положительная цена в рублях;
- `url` — абсолютная HTTP(S)-ссылка.

Желательные поля: `storage_gb`, `condition`, `region`, `published_at`. Без них точность группировки и оценки будет ниже.

Для продуктивной интеграции необходимо отдельно проверить условия использования источника, ограничения частоты запросов и допустимый способ обработки данных.
